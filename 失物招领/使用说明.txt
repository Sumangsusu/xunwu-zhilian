============================================
  寻物智联 · 使用说明（请在 Windows 电脑上运行）
============================================

【这是什么】
一个带数据库、账号登录和管理员后台的失物招领网站。
它不是单个网页，需要在本机启动一个小服务，然后用浏览器打开。


【第一次运行：只需 3 步】
1. 安装 Node.js（LTS 长期支持版）
   下载地址：https://nodejs.org
   下载后一直点“下一步”安装即可。

2. 双击本文件夹里的「启动寻物智联.bat」
   - 第一次运行会自动联网安装依赖（约 1~2 分钟，需要联网）。
   - 安装完成后会自动打开浏览器进入网站。
   - 以后每次使用都直接双击这个 bat 即可。

3. 使用期间，请保持弹出的黑色服务窗口（标题为 XunWu Server）开着；
   关掉它，网站就停止了。


【登录账号】
· 通过登录页注册新账号。
· 管理员授权和部署方法见 DEPLOY.md。


【怎么访问】
· 本机浏览器：http://localhost:3000
· 让同一 WiFi 下的手机或其他电脑访问：
  用本机的局域网地址（可用 ipconfig 查询，形如 http://192.168.x.x:3000）。
  首次运行若弹出 Windows 防火墙提示，请点击“允许访问”。


【数据存在哪里】
· 所有用户、物品、反馈都保存在文件夹：data\xunwu.db（一个 SQLite 文件）。
· 删除这个文件 = 清空全部数据（下次启动会自动重建一个空数据库）。
· 网站只在本机和局域网运行，不连接任何公网服务器。


【把整个文件夹发给别人 / 拷贝到别的电脑】
· 请打包“整个文件夹”，不要只发送单个 HTML。
· 对方电脑只要装好 Node.js，双击「启动寻物智联.bat」即可；
  脚本会自动检测并安装依赖，即使对方的 Node 版本不同也会自动适配。
· 如果想清空对方看到的演示数据，可删除 data\xunwu.db 再启动。
· 最原始的静态原型保存在「Untitled-1-原始雏形备份.html」，无需使用。


【常见问题】
· 双击 bat 后立刻闪退或报错：请先确认 Node.js 已安装成功
  （可在 cmd 输入 node -v 验证），并联网后重试。
· 依赖安装失败：一般是网络问题，请换网络后重新双击 bat。
· 浏览器提示无法访问：说明服务没启动，重新双击 bat；
  若提示端口 3000 被占用，请关闭占用该端口的程序。
· 手机/其他电脑打不开：确认在同一 WiFi，并在防火墙弹窗里选择“允许”。

注：本启动脚本适用于 Windows。若使用 Mac，需要在 Mac 上执行
npm install 后运行 npm start（.bat 批处理在 Mac 上不适用）。
